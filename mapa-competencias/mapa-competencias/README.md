# Mapa de Competências do Grupo

Protótipo da ideia para o programa de ideias da empresa: um mapa de quem sabe o quê em todas as empresas do grupo.

## O que dá para fazer

- **Encontrar pessoas** por habilidade, certificação ou nome
- **Pedir ajuda** a um colega de outro projeto, abrindo um chamado direto para ele
- **Montar equipe**: o sistema sugere a menor equipe que cobre o que o projeto precisa
- **Riscos e lacunas**: habilidades que dependem de uma pessoa só e certificações perto de vencer

## Tecnologia

Página estática (HTML, CSS e JavaScript puro), sem build. Os dados são fictícios.
